# GetYourCard

GetYourCard is a fintech product concept designed to simplify the credit card discovery and application process.

The product helps users assess their credit card eligibility and identify suitable card options based on their profile.

## Key Features

• Credit card eligibility assessment
• User profile based card recommendations
• Simple digital application journey
• Personalised card discovery
• Potential insurance upsell opportunities

## Tech Stack
(Completely Vibe Coded)
• React
• TypeScript
• Firebase
• Tailwind CSS

## Objective

Build a simple and user friendly fintech experience that helps customers make better credit card decisions while creating opportunities for financial product cross selling.
